# School Fee Portal

A modern, secure school fee management portal built with HTML5, CSS3, and JavaScript.

## Features

- **Student Dashboard** - View fee summaries and payment status
- **Payment Tracking** - Track payment history and receipts
- **Multi-language Support** - English and French translations
- **Responsive Design** - Works on desktop, tablet, and mobile devices
- **Secure Authentication** - Student login system
- **Payment Management** - View and manage school fees

## Pages

- `index.html` - Landing page
- `login.html` - Student login
- `register.html` - Student registration
- `dashboard.html` - Student dashboard
- `payments.html` - Payment management
- `fees.html` - Fee details
- `tracking.html` - Payment tracking
- `receipts.html` - Payment receipts
- `profile.html` - Student profile
- `about.html` - About section
- `services.html` - Services offered
- `contact.html` - Contact information

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Setup

1. Clone the repository
2. Push to your GitHub repository
3. Enable GitHub Pages in repository settings
4. Select `main` branch as the source
5. Access your site at: `https://blianetawe51-oss.github.io/school-fee-portal/`
